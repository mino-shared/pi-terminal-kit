# @isaaclins/pi-arcoiris-refined

A complete, tested 51-token Arcoiris-inspired dark theme for Pi.

After publication:

```sh
pi install npm:@isaaclins/pi-arcoiris-refined@1.0.0
```

Test the release candidate now:

```sh
pi --theme ./packages/pi-arcoiris-refined/themes/arcoiris-refined.json
```

Select `arcoiris-refined` in `/settings` after installation. Pi 0.80.3+ and a truecolor terminal are recommended. The theme remains usable with Pi's 256-color fallback.

No synthetic preview is included. A verified terminal screenshot is reserved for a later release. Provenance and collection licensing are recorded in [THIRD_PARTY_NOTICES.md](./THIRD_PARTY_NOTICES.md).

Uninstall with `pi remove npm:@isaaclins/pi-arcoiris-refined`. Source: [packages/pi-arcoiris-refined](https://github.com/isaaclins/pi-terminal-kit/tree/main/packages/pi-arcoiris-refined).
