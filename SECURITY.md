# Security policy

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/isaaclins/pi-terminal-kit/security/advisories/new). Do not open a public issue for an unpatched vulnerability.

The current supported release-candidate lines are pi-codrive 0.1.x, pi-fish-bridge 0.1.x, and pi-arcoiris-refined 1.0.x. Pi extensions execute with the user's full permissions. Review source before installation. Never send secrets through pane prompts or Fish command arguments.
